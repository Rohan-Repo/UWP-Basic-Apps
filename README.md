# Universal-Windows-Platform-Applications

A collection of basic apps and mini-projects written in C# using the Universal Windows Platform (UWP), backed by MS SQL Server for persistent data storage. This repository is a starter kit for developers exploring native Windows application development with UWP, C#, and enterprise-grade database integration.

---

## Overview

Explore simple to intermediate UWP applications demonstrating GUI design, event handling, data binding, and real database integration. Each app is standalone and designed for hands-on learning and study.

---

## Contents

- **Text-To Speech App**
- **DataBinding Examples**
- **Form Validation Examples**
- **UWP App to Display MS-SQL Server Data** 

---

## Technologies

- C# language
- Universal Windows Platform (UWP)
- XAML for UI
- Microsoft SQL Server (Database)
- ADO.NET or Entity Framework Core for data access
- Windows 10/11 development

---

## Getting Started

1. **Clone the repository**

git clone https://github.com/Rohan-Repo/Universal-Windows-Platform-Applications.git

2. **Set up MS SQL Server**
- Install and configure SQL Server locally or remotely
- Create necessary databases and tables for each app (see code/project docs)
- Update connection strings in the code (App.config or appsettings.json)

3. **Open a project/app folder in Visual Studio**
4. **Build and Deploy**
- Choose "Start Debugging" (F5) to run in your local Windows environment
